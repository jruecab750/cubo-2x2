# Cubo 2x2 manejable

Cubo tipo Rubik 2x2 que el alumnado gira con las manos delante de la cámara (pellizco pulgar–índice) o con el dedo en el móvil.

- Página: https://jruecab750.github.io/cubo-2x2/
- `index.html`: el artefacto, en un solo archivo.
- `cubo-2x2.txt`: copia idéntica para pegar en Google Sites (Insertar → Código).

El vídeo de la cámara no sale del equipo.
